# 个人作品集网站

一个纯原生前端实现的个人作品集单页网站，展示个人信息、技能、作品项目、经历与联系方式。

## 功能特性

- 🌙 **深浅色主题切换**：一键切换，自动记忆用户选择（`localStorage`），并优先跟随系统偏好
- 🎬 **卡片懒加载级联动画**：作品卡片进入视口后按序级联显现
- 🔍 **作品分类筛选**：支持「全部 / 网页应用 / UI 设计 / 移动端」快速筛选
- ✨ **滚动入场动画**：区块进入视口时渐入，技能条与数字统计自动触发
- 🖩 **打字机效果**：Hero 区多短语循环打字
- 📱 **响应式布局**：桌面端与移动端适配，移动端抽屉式菜单
- 📝 **表单校验**：联系表单前端校验与成功反馈
- 📄 **简历下载**：一键生成并下载简历文本
- 🎯 **辅助细节**：自定义光标、回到顶部、预加载动画

## 页面结构

| 区块 | 说明 |
|---|---|
| Hero 首屏 | 简介、打字机、CTA、社交链接 |
| 关于我 | 个人介绍、信息与数据统计 |
| 技能 | 进度条 + 图标矩阵 |
| 精选作品 | 项目卡片 + 分类筛选 |
| 经历 | 时间线 |
| 联系我 | 联系信息 + 留言表单 |

## 技术栈

- 原生 **HTML / CSS / JavaScript**（无前端框架、无第三方 UI 组件库）
- 图标：Font Awesome 6
- 字体：Google Fonts（Poppins / Noto Sans SC）
- 存储：`localStorage`（主题记忆）
- 说明：`demo/` 下另有一个独立演示页（Tailwind CDN 版），与主页面互不影响

## 运行方式

项目为纯静态站点，任意静态服务器均可运行：

```bash
# 方式一（推荐）：Python 内置服务器
git clone <仓库地址> && cd lab04
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# 方式二：直接用浏览器打开 index.html 文件
```
